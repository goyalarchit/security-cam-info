Privacy policy

Security Cam is a personal utility. Last updated: 19 October 2026.

Data and access

The utility uploads security cam snapshots and metadata to a private Google Drive folder. It requests the drive.file permission to create and manage files used by the utility, rather than general access to your Drive.

Encrypted device connection credentials are stored in the utility's Drive folder to support unattended operation. Account credentials, Google authorization credentials, and the encryption key are stored separately in the operator's private GitHub Actions secrets.

Use and sharing

Data is used to operate the utility and maintain the user's snapshot archive. It is not sold or used for advertising. Google and GitHub process data as necessary to provide storage and automation. Access to and use of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Uploaded files remain until the user deletes them. Users can stop the automation, delete stored files, remove saved credentials, and revoke Google access through their Google Account's third-party connections settings. Revoking access does not automatically delete files already uploaded.

This website and contact

This site contains no embedded analytics or advertising. GitHub Pages may process technical request information under GitHub's privacy statement.

Contact the maintainer through the support issues page. Do not include credentials, snapshots, or other private information in public issues.
